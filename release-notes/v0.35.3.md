# Changelog

### Features ☀️

- Add optional historical baselines for solar production, grid export, electricity prices, and feed-in compensation before Home Assistant recorder data begins.
- Add historical battery charge and discharge totals as aggregate estimates.
- Add historical heat-pump electricity and heat totals, including clearly marked COP-based heat estimates.
- Add historical wallbox/EV charging and comparable combustion-car consumption baselines.
- Include configured historical totals in lifetime savings and payback calculations without creating synthetic hourly or monthly recorder data.

### Improvements

- Keep historical baselines disabled by default for existing installations.
- Preserve configured historical values when the feature is disabled.
- Validate the historical start date against the first available recorder data to prevent double counting.
- Clarify limitations: average prices cannot reconstruct dynamic tariffs or exact battery timing, and aggregate battery results are estimates.
