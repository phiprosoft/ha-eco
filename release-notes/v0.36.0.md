# Changelog

### Features

- Allow a heat-pump COP entity to provide live hourly COP values instead of requiring a current manual COP input.
- Allow electric-car consumption and comparable combustion-car consumption entities to provide live values for savings calculations.
- Generalize category entity sources so additional live sensor-backed values can be configured consistently.

### Improvements

- Allow the current fuel price to come from an entity without requiring a duplicate manual current price.
- Keep historical averages and aggregate baselines independent from live entity sources, preserving calculations before the sensor data begins.
- Fall back to configured manual values when a selected entity has no usable reading.
- Keep entity-backed configuration fields optional when a valid source entity is selected.
